# 安全与资源限制

MoonFraming 会把对端发来的长度和内容视为不可信输入。

- 长度值在分配完整载荷前与 `max_frame_size` 比较。
- uLEB128 头最多五字节，超界高位和未结束继续位都会报错。
- 固定宽度头在计算长度修正后再检查下溢和帧上限。
- 分隔符长时未出现也会触发缓冲上限，不会无限等待。
- `finish` 用于区分“还在等下一块”和“连接或文件已截断”。
- CRC-32 只检测非恶意损坏。需要防篡改时应在上层使用 TLS、MAC 或数字签名。

建议服务端根据业务协议显式设置两个上限，不要盲目使用默认值。错误后只有在上层确认了新边界时才应调用 `reset`。
